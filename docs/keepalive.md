# 保活教程（Android）

目标：让「电量中枢」在息屏、清理后台、重启之后**自动继续上报**。

前台服务只是及格线。国产 ROM 会把前台服务也一起冻结，必须手动开白名单。

---

## 一、先理解为什么会被杀

| 机制 | 表现 |
|---|---|
| 电池优化（Doze） | 息屏几分钟后网络被掐，`age_sec` 一直涨 |
| 后台冻结 | 进程还在，但不再执行定时任务 |
| 自启动拦截 | 重启后服务根本没起来 |
| 一键清理 | 从最近任务划掉，进程被杀且不再自启 |

前三个靠白名单解决，最后一个靠"锁定最近任务"。

---

## 二、通用四件套（所有国产 ROM 都有对应项）

1. **允许自启动**
2. **允许后台运行高耗电**
3. **电池优化设为"不受限制"**
4. **在最近任务里锁定卡片**

---

## 三、分机型路径

### iQOO / vivo（OriginOS，实测 Android 15）

| 步骤 | 路径 |
|---|---|
| 1. 自启动 | `i管家` → 应用管理 → 自启动 → 找到「电量中枢」→ 打开 |
| 2. 后台高耗电 | 设置 → 电池 → 后台耗电管理 → 电量中枢 → **允许后台高耗电** |
| 3. 电池优化 | 设置 → 应用 → 电量中枢 → 电池 → **不受限制** |
| 4. 锁定任务 | 打开「最近任务」→ 长按（或下拉）电量中枢的卡片 → 点锁图标 |

> OriginOS 的「i管家」是独立 App，权限和系统设置分开管，**两个地方都要设**。

### OnePlus / OPPO（OxygenOS，实测 Android 16）

| 步骤 | 路径 |
|---|---|
| 1. 自启动 | 设置 → 应用 → 自启动管理 → 电量中枢 → 打开 |
| 2. 后台运行 | 设置 → 电池 → 应用耗电管理 → 电量中枢 → **允许后台运行** |
| 3. 电池优化 | 同上 → 「智能省电」里把它排除 |
| 4. 锁定任务 | 最近任务 → 卡片右上角 ⋮ → 锁定 |

### 小米 / 红米（HyperOS）

`设置 → 应用设置 → 应用管理 → 电量中枢 → 省电策略 → 无限制`
+ `自启动` 打开
+ 最近任务下拉卡片锁定

### 华为 / 荣耀

`设置 → 应用 → 电量中枢 → 耗电详情 → 应用启动管理 → 改为「手动管理」，三项全开`

---

## 四、开发者选项里的两个坑

| 设置 | 必须 | 原因 |
|---|---|---|
| 「不保留活动」 | **关闭** | 打开后每次切后台都销毁 Activity |
| 「后台进程限制」 | **标准** | 设成"最多 1 个进程"会直接把服务挤掉 |

---

## 五、验证是否真的保住了

**方法一：看时间戳**

在电脑上打开 `http://127.0.0.1:18080/`，看对应设备卡片上的「更新于 X 秒前」。

- 正常：息屏 5 分钟后，`age_sec` 应该 **< 60 秒**（每 15 秒上报一次）
- 被杀：`age_sec` 会一直涨到几百秒

**方法二：看通知栏**

服务活着时，通知栏常驻一条「电量中枢 · 本机 XX% / 外设 N 台」。这条消失就是被杀了。

**方法三：重启手机**

重启后 1 分钟内，看面板上该设备是否自动回到"在线"。

---

## 六、系统更新后必须复查

大版本更新（尤其 OriginOS/OxygenOS）**会把第三方 App 的白名单重置**。

更新完请重做第三节的第 1、2 条，其余一般保留。

---

## 七、症状对照表

| 症状 | 最可能的原因 |
|---|---|
| 息屏几分钟后数据不动，亮屏立刻恢复 | 电池优化没设"不受限制" |
| 重启后完全没数据，手动打开 App 才恢复 | 自启动 / 开机自启没开，或 `BOOT_COMPLETED` 被拦 |
| 从最近任务划掉后再也不上报 | 没锁定卡片 |
| 通知栏常驻通知消失 | 服务被系统杀了；检查是否被"一键加速"清掉 |
| 装完 APK 后不更新 | 覆盖安装会杀进程；本项目已用 `MY_PACKAGE_REPLACED` 自启，若仍不更新说明自启动被拦 |

---

## 八、本项目已做的（代码层）

- `foregroundServiceType="connectedDevice"` 前台服务 + 常驻低优先级通知
- `START_STICKY`：被系统杀死后自动重建
- `BOOT_COMPLETED`：开机自启
- `MY_PACKAGE_REPLACED`：**覆盖安装后自启**（`START_STICKY` 救不了这个场景）
- 上报心跳 10 分钟，中枢 30 分钟收不到就判离线（方便你发现它死了）

代码只能做到这里，剩下的必须靠上面的白名单。
