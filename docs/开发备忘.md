## 1. 采集实现

| 端 | 采集内容 | 方式 |
|---|---|---|
| 手机 / 平板 | 自身电量、充电 | `BatteryManager` 粘性广播 |
| 手机 / 平板 | 每台已配对蓝牙耳机的电量 | 反射 `BluetoothDevice.getBatteryLevel()`（隐藏 API） |
| 手机 / 平板 | 每台外设是否连接 | 反射 `BluetoothDevice.isConnected()` |
| PC | 自身电量、充电、是否插电 | `GetSystemPowerStatus` |

扫描频率 **15 秒一次**，扫的是系统「已配对设备」列表（`getBondedDevices()`），不是扫描周围信号。

> 为什么不用 `BATTERY_LEVEL_CHANGED` 广播？实测在这台机器上一次都不触发。
> 为什么不用 `dumpsys bluetooth_manager`？vivo 把这部分 dump 掏空了，输出 0 字节。

## 2. 上报与离线

| 触发条件 | 是否立即上报 |
|---|---|
| 电量与上次相比变化 ≥ 1% | ✅ 立即 |
| 充电 / 插电状态翻转 | ✅ 立即 |
| 外设连接状态变化 | ✅ 立即 |
| 以上都没有 | 每 **10 分钟**一次心跳 |

中枢超过 **30 分钟**没收到某节点上报 → 标记离线并变灰。
状态写进 `state.json`，中枢重启后恢复，全部先标离线、等重新上报。

## 3. 外设显示与归属

**显示条件**（缺一不可）：在系统「已配对」列表里；并且**有过至少一次电量读数 或 当前正在连接**。

> 从来没读到过电量、现在也没连着的设备**不显示**（避免面板挂一堆 `—`）。
> 但「连着却读不到电量」的设备**会显示**，电量显示 `—` —— 因为「连着」本身是有效信息。

**显示内容**：有历史电量 → 显示最后一次读到的值，断开后保留；从未读到 → `—`；
断开的外设整行变灰，名字前加 `·`。

**归属（支持 TWS 多点连接）**：

| 情况 | 显示 |
|---|---|
| 两台都连着 | **两边都显示**，都带 `（双设备）`，各自显示各自电量 |
| 只连一台 | 只挂那台，不带标记 |
| 都断开 | 挂到「最后一次稳定连过」的那台（= 下次自动连回的设备），灰色 + 最后电量 |

- 存储键是 `(设备, 外设)`，同一只耳机在每台设备下独立记录；
- 某台设备报「已断开」只影响它自己那条，不会删掉另一台的；
- 不存在「抢归属」：连着就挂、断了就不挂，断开时才回落到最后那台；
- 外设所属设备离线时，该外设跟着变灰。

## 4. `null` 不等于 `0`

| 字段 | 取值 | 含义 |
|---|---|---|
| `pct` | `0..100` | 正常 |
| `pct` | `null` | **读不到**（不是没电） |
| `charging` | `true` | 正在充电 |
| `charging=false, ac=true` | | 插着电但已充满 |
| `charging=false, ac=false` | | 电池放电中 |

界面上 `null` 一律显示 `—`，绝不显示 `0%`。

## 5. 类型识别（图标）

三层兜底，命中即止：

| 顺序 | 依据 | 例子 |
|---|---|---|
| 1 | `BluetoothClass.getDeviceClass()` | `0x0540`→键盘、`0x0580`→鼠标、`0x04xx`→音频 |
| 2 | 名字关键词 | `耳机/buds/tws/anc/头戴/keyboard/mouse/鼠标/平板/pad…` |
| 3 | 型号前缀 | `K###`→键盘、`M###`→鼠标（联想等厂家惯例） |
| 4 | 兜底 | 通用圆环 |

音频类再按名字区分**头戴**（大弧+耳罩）和**豆式**（两颗小豆），因为蓝牙类分不出来。

## 6. 节点识别与别名

节点 id 由机型自动生成（`Build.MODEL`），**同一个 APK** 装到手机和平板不会互相覆盖。

改名不用重装，编辑 `config.json`：

```json
"aliases": {"opd2513": "平板"},
"periph_aliases": {"6c1629715c35": "蓝牙耳机"}
```

- `aliases` 改**设备**名，键是 node id；
- `periph_aliases` 改**外设**名，键是 MAC 去掉冒号。

## 8. 数据格式

### `POST /report`

```json
{
  "node": "iqooz8",
  "name": "iQOO Z8",
  "ts": 1763270000,
  "battery": { "pct": 87, "charging": false, "ac": false },
  "peripherals": [
    { "id": "cc14bcadbc77", "name": "EDIFIER W820NB", "pct": 90, "connected": true, "cls": 1028 }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `pct` | `null` = 读不到（不是没电） |
| `charging` | 正在充电 |
| `ac` | 插着电源（充满时 `charging=false, ac=true`） |
| `connected` | 该外设当前是否连着 |
| `cls` | `BluetoothClass.getDeviceClass()`；BLE 设备常为 -1 |

校验：`pct` 必须 0..100 或 null；`node` ≤ 40 字符。

### `GET /state`

```json
{ "hub_ts": 1763270000, "count": 3,
  "nodes": [ { "node":"pc", "name":"Win10 笔电", "online":true, "age_sec":3,
               "battery":{...}, "peripherals":[...] } ] }
```

### 其它端点

| 端点 | 用途 |
|---|---|
| `GET /health` | `{"ok":true,"uptime":..,"nodes":N}` |
| `GET /apk` | 下载最新 APK（带 `Content-Disposition: attachment`） |
| `GET /` | 网页面板（5 秒刷新） |

## 9. 构建 APK

需要 JDK 17 + Android SDK（platform-35、build-tools 35）。仓库**不含**这些（体积太大）。

```powershell
# 1) 写中枢地址（这个文件不进 git）
copy android/probe/hub_urls.example.txt android/probe/hub_urls.txt
notepad android/probe/hub_urls.txt

# 2) 构建
powershell -ExecutionPolicy Bypass -File tools/build_probe.ps1

# 3) 安装
adb install -r -g android/out/probe.apk
```

- `-g` 很关键：一次授予全部运行时权限；某些 ROM（如 OxygenOS 16）不允许 `pm grant`。
- 装完去桌面长按空白 → 小组件 → 选 `电量中枢 2×2 / 4×2 / 4×4`。
- **覆盖安装新 APK 后，桌面小组件必须删掉重加**，否则系统沿用旧的 RemoteViews。

地址清单（`hub_urls.txt`，每行一条，按顺序试）：

```
http://192.168.1.100:18080/report     # 局域网 IPv4
http://[fd00::1]:18080/report         # IPv6
http://127.0.0.1:18080/report         # adb reverse 兜底
```

## 10. 踩坑记录（复现时会遇到）

| 现象 | 原因 | 处理 |
|---|---|---|
| `POST /report` 全部超时，但本机 curl 正常 | Windows 防火墙有 `python.exe` 的 Block 规则，压过端口放行 | 删掉那条 Block 规则 |
| 装完 APK 后数据不再更新 | 覆盖安装会杀进程，`START_STICKY` 救不了 | 已内置 `MY_PACKAGE_REPLACED` 自启 |
| `pm grant` 报 `GRANT_RUNTIME_PERMISSIONS` 拒绝 | Android 16 / OxygenOS 限制 | `adb install -g` |
| 配置文件读不出来 | PowerShell `Set-Content -Encoding UTF8` 写了 BOM | 用无 BOM 写入（Python 或 `[IO.File]::WriteAllText`） |
| 中文源码编译报错 | 同上，Java 源码被加了 BOM | UTF-8 无 BOM 保存 |
| Tk 文字重叠 / 被裁 | Windows 125% 缩放：字体按磅、坐标按像素 | 统一乘 DPI 因子，字号用负值 |
| 字号放大后卡片内文字压到电量条 | 行高没跟着字号缩放 | `draw_card` 里所有纵向偏移乘 `font_scale` |
| 窗口跑出屏幕右边缘 | DPI 125% 下窗口变宽 | `restore_pos` 里按屏幕尺寸钳制 |
| `.cmd` 启动 frpc 偶发失败 | `start "" cmd /c ""exe" -c "cfg" > log"` 嵌套引号被 cmd 解析错 | 改用 `powershell -Command Start-Process` |
| frp 日志配置报 `json: unknown field "filePath"` | frp 0.72 没有这个字段 | 路径直接写进 `log.to` |
| 隧道域名解析不出来 | 误把 `serverName`（TLS 证书名）当访问域名 | 用 `serverAddr` + `remotePort` |
| 手机能装 APK、平板"无法识别" | 下载没落成 `.apk` / 未知来源没开 | `/apk` 已加 `Content-Disposition`；用文件管理器打开 |
| 平板 ARP 电脑返回 `INCOMPLETE` | 校园网不代理 ARP / 隔离客户端 | 只能走隧道，别指望局域网 |
| mDNS / SSDP 0 响应 | 组播被禁 | 没做自动发现，地址手写 |
| Tailscale 开着连不上局域网 | 劫持路由（`vgate0` + 策略路由） | 关「使用 Tailscale DNS」和「出口节点」 |

## 11. 技术选型说明

- **没有 MQTT**：`hub/broker.py` 是早期备选，实测 amqtt 在长连接下会静默断连，已弃用。
- **没有数据库**：状态就是一个 `state.json`，重启可恢复，够用。
- **没有自动发现**：组播被禁，地址只能手写或多条回退。
- **Android 不用 Gradle**：手工 `aapt2 → javac → d8 → zipalign → apksigner`，
  避免 Gradle 下载依赖；代价是加第三方库麻烦，所以零依赖。
